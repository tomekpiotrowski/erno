# Erno App

Angular 22 library (`erno-angular`) for Ionic web and mobile. Commands run from `app/`.

```sh
ng build erno-angular
ng test
```

Consuming apps import `ErnoModule`. This library must not contain Ionic-specific code.

Narrative docs: `docs/src/content/docs/app/`. Update the matching page when you change a public API, configuration, or observable behaviour.
